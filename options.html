TagExtract Options

SD prompt weights, tag blacklist, rating filter, and per-site overrides

Copy format

SD prompt emits (tag:1.10) numeric weights. Works in both A1111 and ComfyUI. Parens in tags are auto-escaped.
Anima expects @artist name. When enabled, each artist tag becomes e.g. @hoshino aquamarine. Anima tags are always lowercased and space-separated.
High weight may cause artifacts
Placeholders: {tags} (all tags), {copyright}, {artist}, {character}, {meta}

Tag processing

Case-insensitive. Examples: commentary, bad *, *(cosplay). Patterns match the tag as shown on that site (Danbooru and e621 use spaces).

Replacement rules

Applied to each tag in order before copying. Find is matched as literal text. Leave Replace empty to delete a tag. Example: 1girl → 1girl, solo.

Rating filter

Ratings are normalized across sites (Danbooru g/s letters map to safe/sensitive; other sites' s maps to safe). Gelbooru listings do not expose ratings, so posts on those listings are never excluded. At least one rating stays checked.

Behavior

Fires once per post. Auto-copies are not added to copy history.

Per-site overrides

Override global format, prefix, and tag style for a specific site.

Shortcuts

Ctrl + Shift + 1 (Copy Tags)   ·   Ctrl + Shift + 2 (Copy All)
Remap at chrome://extensions/shortcuts.
